How the matching works

A file links to a word when its basename equals the word's english_word, compared case-insensitively with runs of whitespace collapsed. No fuzzy or stem matching — Zinni.jpeg will not find Zinnia.

Uploads land in Cloudinary under words/{word_id}. Each one writes a dc_files row and points dc_word_media.image_id at it. Words that already have an image are never overwritten, so node scripts/upload-word-images.js is safe to run again after you close gaps.
